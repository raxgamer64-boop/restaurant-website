# Datta Restaurant Website v5 — UPI + Quantity

Features:
- Datta Restaurant branding and WhatsApp ordering
- Menu quantity controls and cart
- Table / private room booking to WhatsApp
- UPI payment using 9546320565-2@ibl
- UPI QR code for PhonePe, Google Pay, Paytm and other UPI apps
- Payment confirmation button that opens WhatsApp
- GitHub Pages compatible static website

Important:
- Menu prices are still demo/sample prices. Replace them with the real restaurant menu before launch.
- UPI payments are not automatically verified by this static site. The restaurant should verify the payment in its UPI/bank app and ask customers to send the payment screenshot.
- No UPI PIN, OTP or bank password is stored by the website.
