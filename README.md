# Dutta Restaurant — Premium Static Website

This package is a GitHub Pages-ready static restaurant website with a browser-local owner dashboard.

## Included
- Cinematic responsive homepage
- 3D-inspired depth, tilt cards, parallax and scroll reveal (no heavy WebGL dependency)
- Menu filters, gallery lightbox, WhatsApp reservations, click-to-call
- Mobile sticky contact actions
- Owner dashboard for restaurant info, homepage copy, menu, gallery and backup/reset

## Important
The admin currently stores edits in the browser's localStorage. That means edits are not published to every visitor. For a real multi-device production CMS, connect the same admin UI to Firebase/Supabase later.
