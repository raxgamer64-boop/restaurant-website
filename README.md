# Datta Restaurant Website

Static GitHub Pages website for Datta Restaurant, Maheshpur, Pakur, Jharkhand.

## Included
- Mobile-friendly restaurant landing page
- Sample menu with cart and WhatsApp ordering
- Table booking form
- Private room / birthday party booking form
- Google Maps search link for the supplied address
- WhatsApp number: +91 95463 20565
- Optional Razorpay Payment Link support

## Important before launch
1. Replace the demo menu prices/items in `config.js` with the restaurant's real menu.
2. Add the restaurant's public Razorpay Payment Link to `RESTAURANT.paymentLink` if online advance payment is required.
3. Replace the generic online photos with the restaurant's own photos when available.
4. GitHub Pages is static: booking requests are sent to WhatsApp. It does not provide a live reservation database or real-time table availability by itself.

Never put a Razorpay secret key in this frontend code.
