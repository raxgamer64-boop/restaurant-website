# Saffron House — Sellable Restaurant Website

## Run
Open `index.html` directly in a browser, or use VS Code + Live Server.

## Customize for a client
Edit these items in `index.html`:
- Restaurant name: `SAFFRON HOUSE`
- Phone / WhatsApp: `919999999999`
- Address: `12 MG Road, Patna, Bihar`
- Menu names and prices
- Google Maps link
- Instagram link
- Opening hours

## Free deployment
Upload the three files (`index.html`, `style.css`, `script.js`) to a GitHub repository and deploy the repository with a free static hosting service such as GitHub Pages or Cloudflare Pages.

## Important
The food visuals in this starter are CSS/emoji placeholders. Replace them with the client's licensed photos for the final paid website.
